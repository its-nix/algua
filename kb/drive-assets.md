The Algua Drive folder was **empty** when inspected. This public GitHub repository must not expose credentials, brokerage account data, protected datasets, private agreements or secret-bearing Drive files. The Drive folder is access-controlled; a link is not access permission.

## Transfer rule

1. Keep executable truth, data contracts, strategy notes, experiment provenance and research gates in GitHub/Algua's actual storage and validation workflows.
2. Put an original business asset in Drive only when it is a document or media asset; reference it in a GitHub KB note by link and non-sensitive metadata if this is safe for **public** readers.
3. Send only generalizable, safely sourced findings to the private company KB through its evidence-backed PR workflow, linking here instead of copying technical data.
4. After moving a Drive file, update the exact pointer in the owning KB note and verify both destination and access; do not implement two-way synchronization.

A Drive document or company KB summary must never override existing human go-live authorization, data integrity, holdout, or other enforced controls.
